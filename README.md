# Анализатор страниц
Приложение предназначено для SEO-анализа веб-страниц. Стек технологий: Java (бэкенд), Javalin (веб-фреймворк), JTE (шаблонизатор). Для хранения данных в процессе разработки и тестирования применяется H2, в продакшен-среде — PostgreSQL. Внешний вид реализован с использованием Bootstrap.
